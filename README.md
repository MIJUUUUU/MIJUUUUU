## About Me

사용자의 문제를 데이터로 이해하고, AI 기술을 실제 기능으로 연결하는 **AI Service Developer**를 지향합니다.

- 흩어진 데이터를 분석 가능한 형태로 정제하고 구조화합니다.

- RAG, LLM, 이상 탐지 모델을 서비스 기능과 연결하고 사용자 흐름으로 구현합니다.
